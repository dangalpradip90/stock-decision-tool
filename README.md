# 株式・円相場・国内IPO判断ツール

株価・企業指標・USD/JPYを組み合わせた上場株式分析と、JPX公式情報をインターネットから自動取得する国内IPO評価を1つにまとめたStreamlitアプリです。画面は日本語・ネパール語・英語に切り替えられます。

## 主な機能

- 米国株・日本株の株価、移動平均、RSI、ATR、ボラティリティ、最大下落率
- ファンダメンタル、バリュエーション、テクニカル、円相場、決算日リスクの総合評価
- USD/JPYの3か月変化と50日平均から、円高方向・円安方向・方向感なしを判定
- 海外株、円安メリットの輸出型、円高メリットの輸入型、中立を分けた為替判断
- 3段階の分割買いゾーンと、許容損失・最大配分から計算する数量上限
- JPXの新規上場一覧、会社概要PDF、Iの部PDFを自動取得
- 国内IPOの成長性、収益性、参考PER、需給、公募・売出構成を100点で評価
- Yahoo Financeの制限時に価格チャートAPIへ自動フォールバック

アクセス制限を増やしやすかった一括スキャンと、見出しだけでは信頼性が低いニュース自動採点は削除しました。

## 円相場の見方

Yahoo Financeの `JPY=X`（1米ドル当たりの円）を使用します。

- 数値が下がる: 円高方向
- 数値が上がる: 円安方向
- 海外株: 円高方向は円から買いやすく、円安方向は円換算利益の確定を検討しやすい
- 輸出型の日本株: 一般に円安が業績の追い風になりやすい
- 輸入型の日本株: 一般に円高がコスト面の追い風になりやすい

日本株の為替影響は企業ごとの海外売上、海外生産、輸入コスト、為替ヘッジで変わります。そのため自動判定では日本株を中立にし、分かる場合だけサイドバーで輸出型・輸入型を選びます。

円相場だけで売買は決めません。総合スコアでは企業業績と株価トレンドも同時に評価します。

## 国内IPOの使い方

左側の「国内IPO判断」を選びます。JPXから取得した銘柄一覧が表示されるので、会社を選んで「ネットから取得して評価」を押してください。数値の手入力はありません。

アプリは次の情報を自動取得・計算します。

- 上場予定日、証券コード、市場
- 公開価格または仮条件上限
- 公募株、売出株、オーバーアロットメント
- 上場時発行済株式数、時価総額、吸収金額
- 最新2期の売上成長率、経常利益率、EPS、参考PER

公開価格が未決定の場合は仮条件上限を使った暫定評価になります。PDFの形式によって抽出できない項目がある場合は、自動取得率を下げ、強い申込判定が出ないよう制限します。

IPOスコアは初値を予言するものではありません。赤字、割高、大型吸収、高い売出比率を整理するための申込前チェックです。ロックアップ解除条件、資金使途、主要株主、業績予想は必ず公式PDF本文で確認してください。

JPX新規上場会社情報: https://www.jpx.co.jp/listing/stocks/new/index.html

## リスク管理

サイドバーで利用可能資金、1回の取引で許容する損失率、1銘柄への最大配分率を設定できます。数量上限は両方を超えないよう計算し、日本株ティッカー（`.T`）は100株単位に切り下げます。

表示されるリスク見直し価格は、ATRと価格の一定割合から計算した検討基準です。ストップ注文の約定を保証せず、窓開けや急変時には想定を上回る損失が発生する可能性があります。

## 起動方法

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux / WSL
source .venv/bin/activate

python -m pip install --upgrade pip setuptools wheel
python -m pip install -r requirements.txt -c constraints-py38.txt
python -m streamlit run app.py
```

ブラウザで通常 `http://localhost:8501` が開きます。

ティッカー例:

- 米国株: `NVDA`, `MSFT`, `AMZN`
- 日本株: `6501.T`, `6857.T`, `9984.T`

## Python 3.8対応

依存関係はPython 3.8で動く版に固定しています。`multitasking`の新しい版にある型構文エラーを避けるため、必ず `constraints-py38.txt` も指定してください。

## 注意

このツールは投資助言でも利益保証でもありません。企業開示、目論見書、取引所情報、為替と市場環境を確認し、損失に耐えられる範囲で最終判断してください。
